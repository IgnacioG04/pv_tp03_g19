# Gestion de Proyectos Educativos - TP3

Este proyecto representa la evolución de la plataforma de "Gestión de Proyectos Educativos", migrando de una estructura en HTML/CSS a una aplicación moderna desarrollada con **React** y **Vite**.

## Integrantes - Grupo 19
- **Integrante 1** Gutierrez Ignacio [@IgnacioG04](https://github.com/IgnacioG04)

## Funcionalidades
1. **Visualizacion**: la lista de proyectos se genera de forma automatica mediante el recorrido del estado.
2. **Busqueda en tiempo real**: un buscador que filtra los proyectos por titulo.
3. **Gestion de proyectos**:
   - **Eliminar**: boton en cada tarjeta para remover proyectos del sistema mediante el estado.
4. **Modulo de servicio**: logica encapsulada en `proyectoService.js` que gestiona el arreglo de datos.
